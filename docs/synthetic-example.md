# Synthetic workflow figure

The README figure is generated by `examples/synthetic_consensus.py` with seed **42**. It explains how the APIs connect, rather than measuring experimental performance.

1. **Variable-length traces:** all 16 generated traces are shown against their source point indices. Each samples the same artificial template with independent Gaussian noise; lengths and noise levels vary.
2. **Shared grid:** the same traces are linearly interpolated to 64 endpoint-inclusive relative positions. Mean and variance are interpolated separately. No traces are excluded, and no extra smoothing is applied.
3. **Consensus:** uncertainty-weighted DBA fits a profile to those resampled traces. The blue solid line is the fitted profile; the black dashed line is the known artificial reference. Both line style and colour identify the curves.

All panels share the vertical scale in arbitrary signal units. Source indices and relative positions are not physical time or residue coordinates. No confidence band is shown: the algorithm's returned spread is not a calibrated confidence interval.

## Reproduce

```bash
python -m pip install -e '.[demo]'
python -m examples.synthetic_consensus --seed 42 --out-dir results/synthetic
```

The output includes the figure, all source/resampled traces, consensus values, metrics and figure metadata. The checked-in [figure data](figures/synthetic/) provide an accessible numerical alternative to the README image:

- [Native traces](figures/synthetic/native_traces.csv): trace ID, point index, relative position, mean and noise standard deviation.
- [Resampled traces](figures/synthetic/resampled_traces.csv): the corresponding interpolated values.
- [Consensus and artificial reference](figures/synthetic/consensus.csv): profile mean, returned spread and distinct-read depth.
- [Run summary](figures/synthetic/summary.json) and [figure metadata](figures/synthetic/figure-metadata.json).

For the default seed, the original run converged in 8 iterations. The medoid RMSE was approximately **0.02538**, and the consensus RMSE **0.02526**. That small difference is reported without selecting another seed to enlarge it. These numbers describe this artificial example only; dependency versions can affect numerical details.
