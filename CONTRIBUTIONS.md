# Contributions and attribution

**Jenny Jiang** developed this work during a research project in the Cees Dekker Lab at TU Delft, supervised by **Dr Xiuqi Chen**.

- **Jenny's implementations:** uncertainty-weighted consensus in `cowler/consensus/dba.py`, developed from an existing documented scaffold, and numerical preprocessing in `cowler/consensus/length_normalize.py`.
- **Research analyses:** the selected runners showcase consensus classification, preprocessing comparisons, boundary transfer and medoid robustness, built on shared project algorithms and utilities.
- **Supporting code:** `cowler/align/dtw.py` was written primarily by Dr Xiuqi Chen. The CPIC step finder in `segment.py` was ported from the existing poreFlow workflow. Other supporting modules and imported tests come from the shared `cowler` project; their inclusion does not imply sole authorship by Jenny.
- **Portfolio preparation:** Codex assisted with packaging, documentation, checks and the synthetic demonstration. The demonstration explains how to run the implementations; it is not an original internship deliverable.

These contributions concern implementation and analysis, not invention of DTW or DBA. Detailed [packaging history](docs/provenance/packaging.md) and [original source hashes](docs/provenance/SOURCE_MANIFEST.json) are retained separately. No open-source licence has been added.
